3. ERROS AVERIGUADOS E CORREÇÕES EXECUTADAS
--------------------------------------------------------------------------------

A. ERRO NO DEPLOYMENT DO GITHUB ACTIONS (HttpError 404 / 422)
- Sintoma: Todos os workflow runs anteriores da action "Deploy Vite App to GitHub Pages"
  falhavam no step "Setup Pages" com erro:
  "##[error]Get Pages site failed. Please verify that the repository has Pages enabled...
   HttpError: Not Found".
- Causa Raiz: O workflow .github/workflows/deploy.yml tentava publicar o projeto
  no serviço "GitHub Pages". No entanto, o repositório Heuller/hnc é PRIVADO em
  uma conta do GitHub Free, plano que não dá suporte ao GitHub Pages para repositórios
  privados (a API do GitHub retorna status 422). Além disso, a produção real da
  plataforma é hospedada na VERCEL (https://heuller.vercel.app/) e não no GitHub Pages.
- Correção Realizada:
  1. O arquivo .github/workflows/deploy.yml foi reescrito e convertido em um
     pipeline moderno de CI: "CI - Qualidade e Build".
  2. Foram removidos os passos incompatíveis do GitHub Pages (configure-pages,
     upload-pages-artifact e deploy-pages).
  3. O workflow agora executa:
     - Checkout do repositório
     - Setup do Node.js 20 com cache npm
     - Instalação limpa de dependências (npm ci)
     - Validação estática de linter com Oxlint (npm run lint)
     - Execução da suíte completa de 535 testes unitários + compilação estrita
       TypeScript (tsc -b) + empacotamento Vite de produção (npm run build).
- Resultado: Execução concluída com SUCESSO (Green Checkmark) em todas as branches.

B. ERRO DE PREFIXO DE BASE PATH EM VITE.CONFIG.TS
- Sintoma: O arquivo vite.config.ts continha a instrução:
  base: process.env.GITHUB_ACTIONS ? '/hnc/' : '/'
- Causa Raiz: Durante o build no GitHub Actions, a variável GITHUB_ACTIONS fazia
  o Vite compilar todos os assets com prefixo /hnc/, incompatível com o deploy
  raiz da Vercel.
- Correção Realizada:
  Substituído por:
  base: process.env.BASE_URL || '/'
  Garantindo integridade tanto no build local quanto em pipelines de CI e Vercel.

C. DESSINCRONIZAÇÃO CRÍTICA DE COMMITS E PUSHS ENTRE AS BRANCHES
- Sintoma: Os branches de produção "master" e "main" estavam paralisados no commit
  6870c89 (adiciona cadernos de prompt v3), sem receber nenhuma das correções e

  ux/plano-v3 (commit dda1512).

  6. Push remoto do branch main para origin/main.
- Resultado: master, main e ux/plano-v3 estão 100% idênticos e sincronizados no
  commit 47bad71.
